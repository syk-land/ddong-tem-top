# 자동 아바타

> 캐릭터 생성 시 21개 아바타 풀에서 자동 추첨. UI에서 직접 선택은 없음.

코드: `src/screens/CharacterCreation.vue`, `src/ui/images.ts`
이미지: `public/images/USER/` (21 종)

---

## 동작

```
[캐릭터 생성 진입]
   ├─ 저장된 runAvatar 있음? → 그대로 사용
   └─ 없음 → 21개 아바타 중 무작위 1개 선택
              └─ runAvatar 저장 (런 동안 영구 보존)
```

- **던전 화면 하단**에 현재 아바타 표시
- 런 진행 중에는 아바타 절대 변경 안 됨
- 새 캐릭터 생성마다 새로 추첨

---

## 저장

```ts
localStorage["climetop:run:v1"].avatar   // 현재 런의 아바타
```

- 런 시작 시 결정 → 종료까지 유지
- 사망/클리어 시 다음 런에서 재추첨

---

## 21개 아바타 종류

`public/images/USER/` 디렉토리. 일러스트는 다양한 직업/성별/종족 — 게임 메커니즘과 무관 (외형 only).

---

## 진짜 보스 부활 시

진짜 보스 도전에서 가장 최근 클리어 캐릭터를 부활할 때, 그 캐릭터의 아바타도 같이 부활.

```ts
characterHistory[lastIdx].avatar
```

즉 진짜 보스 화면에서는 본인이 그때 썼던 아바타 그대로 나옴.
