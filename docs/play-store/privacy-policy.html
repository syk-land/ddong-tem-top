1. 수집하는 개인정보

본 앱은 게임 진행 외 별도의 개인정보를 직접 수집하지 않습니다. 다만 아래 외부 서비스를 통해 일부 데이터가 처리됩니다.

  • Google 로그인 (Firebase Authentication) — 사용자가 명시적으로 Google 계정으로 로그인을 선택한 경우에만 동작합니다. Google 이 제공하는 표준 사용자 식별자(UID, 이메일, 표시 이름, 프로필 사진)를 클라우드 저장 식별 용도로 받습니다. 비로그인 사용 시 수집되지 않습니다.
  • Firebase Firestore — 로그인한 사용자의 클리어 횟수·캐릭터 누적 기록을 클라우드에 백업합니다. 로컬 저장과 동기화하며 사용자가 로그아웃 시 클라우드 동기화는 중단됩니다.
  • Google AdMob — 게임 내 보상형 광고(부활/속도 가속/자동 진입) 표시. Google AdMob 은 광고 제공을 위해 광고 식별자(AAID), 일반화된 위치(국가 단위), 기기 정보, 네트워크 정보 등을 처리할 수 있습니다. 상세 내용은 Google 의 개인정보 처리방침을 따릅니다.

2. 데이터 저장 위치

  • 로컬 저장 — 게임 진행 상태, 누적 보너스, 설정값은 단말 내부 저장소(localStorage)에 보관됩니다. 본 앱 외부로 전송되지 않습니다.
  • 클라우드 저장 (선택) — Google 로그인 사용 시 클리어 횟수·캐릭터 기록은 Google 의 Firebase Firestore (asia-northeast3 기본 리전 또는 프로젝트 설정 리전)에 저장됩니다.

3. 광고 (AdMob)

본 앱은 Google AdMob 의 보상형(Rewarded) 광고만 사용합니다. 광고 시청은 전적으로 사용자의 선택이며 시청하지 않아도 기본 게임 플레이는 가능합니다.

  • 광고 식별자는 Google 의 광고 제공 정책에 따라 사용됩니다.
  • 안드로이드 설정 → 개인정보 보호 → 광고에서 광고 식별자를 재설정하거나 맞춤형 광고를 비활성화할 수 있습니다.

4. 어린이 보호

본 앱은 만 13세 이상을 대상으로 합니다. 어린이로부터 개인정보를 의도적으로 수집하지 않습니다.

5. 사용자 권리

  • 로컬 데이터는 앱 내 설정 → 모든 데이터 리셋 또는 안드로이드 시스템의 앱 데이터 삭제를 통해 언제든 삭제할 수 있습니다.
  • 클라우드 저장 데이터는 Google 로그인 상태에서 로그아웃 후 서비스 제공자에게 삭제 요청을 보내실 수 있습니다.
