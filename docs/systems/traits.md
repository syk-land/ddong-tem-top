# 특성 시스템

> 무기/갑옷에 1개씩 부여되는 추가 효과. 4 티어 (하급/보통/희귀/특별).

코드: `src/data/traits.ts` — `WEAPON_TRAITS`, `ARMOR_TRAITS`

---

## 티어 표준화

| 티어 | atk%/def% (베이스) | 가격 | 부가 효과 |
|---|---|---|---|
| 하급 | -0.5 | 8~12G | 페널티만 (명중/회피 -소량) |
| 보통 | 0 | 45~60G | 중립 (속도/명중 ± 5) |
| 희귀 | +0.5 | 100~140G | 가산 보너스 + 명중/관통 |
| 특별 | +1.5 | 190~220G | 흡혈/도트/상태이상%/속도% 등 강력 효과 |

`coef(등급)` + `atk%/def%(특성)` 합산이 weaponAtkCoef / armorDefCoef 의 배율.

## 갑옷 특성

유사한 4티어 구조. 핵심 차이:

### 특별 갑옷 특성 (예시)
- 흡수의: 방어력 +50%, **피격 회복 5%**
- 저주의: 방어력 +50%, **자해 3%**
- 반사의 *: 방어력 +50%, **상태이상 반사** (각 종류별 변형)
- 견고의: 방어력 +50%, **상태저항 +10**

`reflect_burn`, `reflect_slow` 등 갑옷 특수 효과는 `data/traits.ts` 의 `ARMOR_TRAITS` 참조.

---

## `TraitEffect` 인터페이스

```ts
interface TraitEffect {
  공격력_pct?, 방어력_pct?, 전스탯_pct?, 속도_pct?
  명중?, 회피?, 관통?, 행운?, 상태저항?, 마력?
  lifesteal?, self_dot_pct?, vs_undead_pct?, damage_taken_heal_pct?
  burn_chance?, bleed_chance?, poison_chance?
  slow_chance?, blind_chance?, shock_chance?
  resist_burn?, resist_slow?, ... (6종)
  reflect_burn?, reflect_slow?, ... (6종)
}
```

스탯 시스템 (`computeEffectiveStats`)에서 모두 가산/곱셈 반영.

---

## 적용

`rollItem` 생성 시 무작위 트레잇 + 등급 조합 → `tier` 계산 → `effects` 적용.

`ItemInstance.effects` 에 합성된 trait 효과 저장 → 장착 시 `computeEffectiveStats` 가 픽업.
