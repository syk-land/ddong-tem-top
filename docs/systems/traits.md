# 특성 시스템

> 무기 14 + 갑옷 15 종 특성. 4 티어(하급/보통/희귀/특별) × 등급 4 종 = 16 티어 강도 분포.

코드: `src/data/traits.ts`

## 16 티어 강도 분포

```
tier = (grade_level − 1) × 4 + trait_level   ∈ [1, 16]
```

- grade_level: 노말 1 / 레어 2 / 스페셜 3 / 레전드 4
- trait_level: 하급 1 / 보통 2 / 희귀 3 / 특별 4

같은 무기라도 (등급 × 특성) 조합으로 16 단계 강함이 나옴.
**등급 우선 설계**: 인접 티어 ≈ 등가 (예: 노말-특별 4 ≈ 레어-하급 5).

`scoreThresholds.ts` 의 클리어 등급은 `무기 티어 + 갑옷 티어` 합산 (낮을수록 똥템).

## 특성 가치 (`itemValue.ts`)

자동 평가 점수에 직접 합산:
- `공격력_pct` → 공격력 곱셈
- `방어력_pct` → 방어% 곱셈
- `명중` / `회피` / `관통` → 가산
- `속도_pct` → 게이지 가속 보정 (양수면 속도↑, 음수면 둔화)
- `lifesteal` / `damage_reflect_pct` → 별도 효과 점수
- `burn_chance` 등 6종 → 상태이상 트리거 점수
