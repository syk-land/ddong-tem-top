## 등급 (Grade) — v9 곱셈 격차

| 등급 | coef | 가격 multiplier | 의미 |
|---|---|---|---|
| 노말 | 1.0 | × 0.5 | 진입용 (사용 불가급) |
| 레어 | 2.0 | × 1.0 | 초중반 baseline |
| 스페셜 | 3.0 | × 3.0 | 후반 안정 (best 평균 9~10%) |
| 레전드 | 4.3 | × 6.0 | 최상위 (best 평균 50%) |

곱셈 모델 — atk + def 양쪽에 곱해짐. 노말 vs 레전드 4.3배 격차.

```
물리 atk 계수 = baseAtk × coef × (1 + trait_pct)
방어 % 계수  = baseDef × coef × (1 + trait_pct)
```

## 특성 (Trait) — 16종 무기 / 15종 갑옷

`docs/systems/traits.md` 참조.

티어별 효과:
- **하급**: 페널티 (공격력_pct -50%, 명중/회피 -5 등)
- **보통**: 부가 효과만 (명중 +5, 속도 +10% 등)
- **희귀**: 공격력/방어력 +50% + 부가 효과
- **특별**: 공격력/방어력 +50% + 시그니처 효과 (흡혈/원소이상/행운 등)

```
물리 atk = 힘 × baseAtk × coef × (1 + trait_atk_pct) × 3.0
```

trait_atk_pct는 곱셈 인자에 직접 곱해지므로, **하급 (-50%)** 는 ×0.5 / **희귀·특별 (+50%)** 는 ×1.5 효과.

## 티어 (1~16)

```
tier = (grade_level − 1) × 4 + trait_level
```
- `grade_level`: 노말=1 / 레어=2 / 스페셜=3 / 레전드=4
- `trait_level`: 하급=1 / 보통=2 / 희귀=3 / 특별=4

특별-노말 (티어 4) ≈ 하급-레어 (티어 5) — 등급이 주, 트레잇이 부수.

---

## 가격 공식

```
sell_price = TRAIT_PRICE × GRADE_PRICE_MULT
GRADE_PRICE_MULT: 노말 0.5 / 레어 1.0 / 스페셜 3.0 / 레전드 6.0
buy = sell × 1.5
buyback = sell × 0.4
```

| 트레잇 등급 | sell 범위 |
|---|---|
| 하급 | 8~12 |
| 보통 | 45~60 |
| 희귀 | 100~140 |
| 특별 | 190~230 |
