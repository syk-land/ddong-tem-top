## 등급 (Grade) — 4종

| 등급 | 등급계수 (coef) 범위 | 출현 챕터 |
|---|---|---|
| 노말 | 1.00 (고정) | 1+ |
| 레어 | 1.5 ~ 2.0 | 1+ (확률 ↑) |
| 스페셜 | 2.0 ~ 3.0 | 4+ |
| 레전드 | 3.0 ~ 4.0 | 7+ (보스 드랍 가능) |

`coef`는 무기 종합공격계수 / 갑옷 종합방어계수에 곱해짐:
```
weaponAtkCoef = baseAtk × (coef + 특성 공격력%)
armorDefCoef  = baseDef × 2 × (coef + 특성 방어력%)
```

## 특성 티어 (TraitTier) — 4종

| 티어 | 가격대 | 효과 강도 |
|---|---|---|
| 하급 | 5~30G | 약함 / 음수 효과 (녹슨, 부서진 등) |
| 보통 | 30~80G | 중립 / 약한 양수 |
| 희귀 | 80~200G | 명중·관통 등 가산 |
| 특별 | 200~500G+ | 흡혈, 자해, 상태이상%, 속도% 등 강력 |

각 무기/갑옷에 1개 트레잇 적용. 트레잇 풀은 `data/traits.ts`.

**예시 (무기 특성)**:
- 녹슨 (하급): 공격력 -50%, 회피 -3
- 저주의 (특별): 공격력 +50%, 자해 5%

**예시 (갑옷 특성)**:
- 녹슨 (하급): 방어력 -50%, 회피 -5
- 견고한 (희귀): 방어력 +25%, 상태저항 +5

## 티어 (Tier 1~14)

`coef + traitTier` 조합으로 산출:
- 노말+하급 = 1
- 노말+보통 = 2
- ...
- 레전드+특별 = 14

티어가 낮을수록 "똥템" → 클리어 점수 ↓ → 등급 ↑ → 보너스 ↑.

색상 (`ui/colors.ts:tierColorClass`):
- T1~4: 하급 색 (회색)
- T5~8: 보통 색
- T9~12: 희귀 색
- T13~14: 특별 색

## 아이템 벨류 (atkValue / defValue)

`core/itemValue.ts`에서 휴리스틱 계산. 카드 상단의 "공 N.N" / "방 N.N" 표시.

### 무기 atkValue
```
DPS    = baseAtk × (등급계수 + 특성 공격력%) × 무기 공속 × 갑옷 공속 × (마법무기면 마력계수)
+ 명중 × 0.4
+ 관통 × 0.6
+ 행운 × 0.5
+ 흡혈 × 40
+ 자해 × -80
+ 대언데드 × 8
+ 상태이상 발동률 × 30 (각 6종 합산)
+ (마법무기) 마력 특성 × 0.5
```

### 갑옷 defValue
```
방어력    = baseDef × 2 × (등급계수 + 특성 방어력%)
+ 회피 × 0.5
+ 상태저항 × 0.3
+ mpBonus × 0.2 (마력→저항 기여)
+ 피격회복 × 40
+ 자해 × -80
+ 각종 반사 × 10
+ 각종 저항 × 5
```

### 갑옷의 atkValue (공속 영향)
```
+ mpBonus × 0.4 (마법공격 ↑)
+ (speedMult - 1) × 캐릭터 무기 DPS  ← 가속이면 +, 감속이면 -
+ 특성 명중/행운 × 0.4 / 0.5
```

**예**: 판금 (speedMult 0.75) + 도끼 (DPS 30) 장착 시 → 공속 감속 기여 = -7.5.

## 아이템 생성 (`core/items.ts:rollItem`)

```ts
rollItem({
  kind: 'weapon' | 'armor',
  chapter?: number,          // 챕터 기반 등급 풀
  source?: 'shop' | 'boss' | 'treasure' | 'starter',
  forceBaseKey?: string,
  forceTraitTier?: TraitTier,
  forceGrade?: Grade,
})
```

생성된 `ItemInstance` 필드:
- `id`, `kind`, `baseKey`, `trait`, `grade`, `coef`, `tier`
- `buyPrice` (상점 매물용), `buyback` (판매가)
- `effects` (트레잇 효과 풀 적용)
