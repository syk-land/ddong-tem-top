# 스탯 시스템 (v9 — 5스탯 + 곱셈 모델)

> 캐릭터의 5개 기본 스탯에서 모든 파생 스탯이 산출. v9 곱셈 모델.

코드: `src/core/stats.ts` — `computeEffectiveStats()`

---

## 5스탯

| 스탯 | 기본값 | 주요 파생 | 비고 |
|---|---|---|---|
| **힘** | 10 | 물리 atk 곱셈 | `힘 × baseAtk × coef × (1+pct) × 3.0` |
| **민첩** | 10 | 게이지 가속 (+%), 명중 +0.5, 회피 +0.5, 크리 확률 +0.3% | 만능 |
| **체력** | 10 | HP (10×체력 + 50), 방어% +0.3, 상태저항 +0.5 | 탱킹 |
| **마력** | 10 | MP (15×마력 + 30), 마법 atk 곱셈, 상태저항 +0.5 | 마법 빌드 |
| **행운** | 10 | 명중/회피 +0.1, 크리 데미지 +1%, 상태저항 +0.3 | 광역 보정 |

기본 시작 = 모두 10 (총 50pt). 챌린지/메타 보너스로 추가 분배.

## 파생 공식 (v9)

### 공격력 (곱셈 모델, v9.x)
```
물리 atk = physStat × baseAtk × coef × (1 + trait_atk_pct) × ATK_K_PHYS (= 3.0)
마법 atk = 마력     × baseAtk × coef × (1 + trait_atk_pct) × ATK_K_MAGIC (= 1.5) × magicSynergy

physStat:
- 대부분 무기 = 힘
- ranged (숏보우/롱보우/석궁) = 힘 + 민첩 × 0.3   ← v9.x 추가

magicSynergy:
- 마법무기 + 로브 = 1.5  (v9.x 너프, 기존 1.7)
- 그 외 = 1.0
```

### 방어 (% 단위, v9.x)
```
방어% = baseDef × coef × (1 + trait_def_pct) + 체력 × 0.3 × coef   ← v9.x: 체력에도 coef 곱
실효방어% = max(0, 방어% − 관통%)
받는 dmg = max(1, 적 atk × (1 − 실효방어%/100))
```
※ 갑옷 자동 반응(피격 시 발동, [combat.md](./combat.md) 참조) 이 추가 변형을 가함.

### 명중 / 회피 (%p 단위)
```
acc = 60 + 무기 + 트레잇 + 민첩×0.5 + 행운×0.1
eva = 5  + 무기 + 트레잇 + 갑옷 evasion + 민첩×0.5 + 행운×0.1
성공률 = clamp((acc − eva)/100, 0, 1.0)
```

### 게이지
```
누적/틱 = 1 × (1 + 민첩/100) × armorSpeedMult
임계값 = 무기 ticks (검 10 / 건틀릿 7 / 할버드 15)
공격 발동: 게이지 ≥ ticks 도달
```

### 크리티컬
```
확률 = clamp(민첩 × 0.003, 0, 1.0)   # 민첩 100 = 30%, 333 = 100%
배수 = 1.3 + 행운/100                # 행운 100 = ×2.3
```

### 관통 (% 절대값)
```
pen% = 무기 penBonus + magicPenBonus + 트레잇 관통
실효방어% = max(0, 적 방어% − pen%)
```

### 상태저항
```
stRes = 체력×0.5 + 마력×0.5 + 행운×0.3 + 트레잇 상태저항
```

## HP / MP

```
maxHp = 10 × 체력 + 50      # 체력 10 → 150
maxMp = 15 × 마력 + 30      # 마력 10 → 180
```

챌린지 `mpCapFixed` (유지력 상실) 적용 시 maxMp = 30 고정.

마법 스킬 MP 소모: 화염구 50 / 번개창 45 / 바위충격 55 등 (v9에서 대폭 강화). 로브의 `mpBonus +8` (+ 마력 트레잇) 으로 MP +120~150 추가 → 마법 빌드 = 마법무기 + 로브 강제.

## v9 시너지

### 마법무기 + 로브
- 게이지 ×1.15 (속도 가속)
- 마법 atk ×1.5 (시그니처 시너지, v9.x 너프)
- 로브의 마력 +8 → MP 보너스

→ 마법 빌드의 정체성. 시뮬 검증: 마법무기 + 로브 조합이 best armor 자동 선택.
