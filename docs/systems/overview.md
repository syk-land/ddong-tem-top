# 게임 개요

## 한 줄
**"이번 판은 똥템으로 탑을 오르겠습니다"** — 100층 (10챕터 × 10층) 로그라이크, 자동 전투, 영구 사망, 클리어 등급이 낮을수록 누적 메타 보너스가 커지는 역설 시스템.

## 핵심 원칙
- **영구 사망**: HP 0이 되면 캐릭터·골드·장비 모두 소멸
- **자동 전투**: 액션 게이지 100 도달 시 자동 행동 (스킬/평타 확률 픽업)
- **메타 누적**: 클리어 시 등급(F~EX)에 따라 1~10pt 자유 분배 가능. 다음 캐릭터에 영구 적용
- **낮은 등급일수록 이득**: 점수가 낮을수록 다음 판이 강해지는 역설 — 약한 빌드로 클리어 = 메타 빠르게
- **챌린지 1개 선택**: 캐릭터 생성 시 3개 중 1개 선택(또는 미선택)

## 화면 구조
```
스플래시 → (최초) 인트로 만화 → 메인 메뉴
                                    │
                       ┌────────────┼─────────────┐
                       ▼                            ▼
                  새 캐릭터 (3챌린지)         이어하기
                       │
                       ▼
                    캐릭터 생성 (주사위 + 챌린지)
                       │
                       ▼
                    던전 (현재 층 카드 + 진입)
                       │
                ┌──────┼──────┬────────┬──────────────┐
                ▼      ▼      ▼        ▼              ▼
              전투    상점   보물    회복샘        특별 이벤트
                │      │       │        │              │
                └──────┴──── advance ──┴──────────────┘
                          (다음 층)
                       │
                  마지막 층 클리어 → 승리 화면 (보너스 분배)
                  또는 사망 → 게임오버
```
