# 스킬 시스템 (19종)

코드: `src/core/skills.ts` + `src/data/skills.ts`

19종 스킬 = 물리공격 5 + 물리방어 4 + 마법공격 7 + 마법방어 3.
스킬은 **무기/갑옷의 `autoSkill`** 에 묶여 자동 발동되며, 직접 시전 UI는 없다.

## 자동 발동률 (buildBalance.ts)

```
base = 무기 베이스 발동률 (건틀릿 0.18 ~ 할버드 0.70)
grade_mod  = +0.10 (노말) ~ -0.05 (레전드)
trait_mod  = +0.05 (하급) ~ -0.05 (특별)
luck_mult  = 1 + LUCK × 0.005
final = clamp(base × (1 + grade_mod + trait_mod) × luck_mult, 0.05, 0.85)
```

낮은 등급/특성일수록 발동률이 더 높다 (똥템 보정).

### 갑옷 자동 반응 발동률 (피격 시)

별도 시스템 — `0.10 + LUCK × 0.005`. 자세한 동작은 [combat.md](combat.md#갑옷-자동-반응-피격-시).

## MP 게이팅

- 마법 스킬은 MP 40~60 소비 → 로브 (`mpBonus +8`) + 마도서 (`mpBonus +3`) 조합이 사실상 필수.
- 행운으로 발동률을 끌어올려도 MP 부족하면 평타로 폴백.

---

## 챌린지 상호작용

- `noActiveSkills` (평화주의자 등): 무기/방어 액티브 스킬 모두 비활성화 (평타만).
- 갑옷 자동 반응은 별도 시스템이라 **영향받지 않음**.
- `forbidMagicWeapon`: 마법 무기 장착 자체 불가 → 마법 공격 스킬 봉인.
