# 스킬 시스템 (19종)

코드: `src/data/skills.ts` (정의), `src/core/skills.ts` (실행), `src/core/buildBalance.ts` (자동 발동률)

분류 (`SkillKind`):
- `physical_atk` (5)
- `physical_def` (4)
- `magic_atk` (7)
- `magic_def` (3)

물리/마법 구분에 따라 사용 공격력이 달라짐 (v9 곱셈 모델):
- 물리: `eff.공격력` = 힘 × baseAtk × coef × (1+pct) × 3.0
- 마법: `eff.마법공격력` = 마력 × baseAtk × coef × (1+pct) × 1.5 × magicSynergy
  - magicSynergy: 마법무기 + 로브 = 1.7 (그 외 = 1.0)

마법 무기의 MP 소모: 스킬 mp + `eff.weaponMpBonus`.

> MP 40~60 → 균등(마력 12) MP 210 캐릭터는 화염구 4회만 사용 가능. 로브 (+8 마력 = +120 MP) 끼면 7회로 충분.

### 마법 광역 패턴
- 빙결의화살: **관통** (앞 3마리)
- 화염구: **메인 + 스플래시** (메인 100%, 나머지 40%)
- 폭풍칼날: **분산 3히트** (개별 명중 굴림)
- 바위충격: **메인 + 광역** (메인 100%, 나머지 70%)
- 번개창: **연쇄** (메인 100% + 50% chain1 + 25% chain2, 확률 60%/30%)
- 그림자일격: 단일
- 정화의광선: 단일 + self-purge

## 스킬 실행 흐름

`useSkill(ctx, key)`:
1. 침묵 상태 체크 (silenceUntilTick)
2. MP 비용 = `skill.mp + (마법무기면 weaponMpBonus)`
3. MP 부족 시 false 반환 → 평타 fallback
4. MP 차감, 스킬 SFX 재생
5. 스킬별 `case` 처리 (스매쉬/피어스/.../정화의광선)
6. trait `onAfterAttacked` / `onHpThreshold` 디스패치
7. 사망 체크

## 챌린지와 상호작용

- `noActiveSkills` (조급증/평화주의자): 공격 스킬 사용 불가 → 평타 강제
- `onlyActiveSkills` (스킬미학): 평타 사용 시 챌린지 실패
- `noIronWill` (의지박약): 불굴의 의지 사용 시 챌린지 실패
- `trackPacifist`: 공격 스킬 사용 카운트 → 실패 처리
