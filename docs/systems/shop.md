# 상점

코드: `src/core/shop.ts`, `src/screens/Shop.vue`

---

## 슬롯 수

```
slots = 3 + floor((chapter - 1) / 3)   ∈ [3, 6]
```

| 챕터 | 슬롯 |
|---|---|
| 1~3 | 3 |
| 4~6 | 4 |
| 7~9 | 5 |
| 10 | 6 |

---

## 카테고리 분포

- 무기 / 갑옷 **50:50** 무작위
- 등급 분포: 챕터 게이팅 (챕터 6 이전은 스페셜/레전드 자동 다운그레이드)
- 특성 풀: 챕터 진행에 따라 상향

---

## 새로고침

```
초기 충전 = 1 (챕터 시작 시 갱신)
최대 충전 = 2
이벤트 부스트 (모험가 동료) 최대 3
새로고침 1회 = 슬롯 전체 재추첨
```

| 행동 | 효과 |
|---|---|
| 챕터 클리어 | 새로고침 +1 (최대 2/3) |
| 모험가 동료 합류 | 새로고침 +1 (최대 3) |
| 새로고침 사용 | 슬롯 전체 재추첨 |

새로고침을 최대치에서 사용 시 다음 챕터에 1회 초기화.

---

## 가격 (`itemValue.ts` 와 동기화)

```
판매가 = 트레잇 가격 × 등급 배수
등급 배수: 노말 ×0.5 / 레어 ×1.0 / 스페셜 ×3.0 / 레전드 ×6.0
구매가 = 판매가 (UI 표시는 동일)
```

플레이어가 아이템 판매 시 동일 식으로 환산.

---

## 챌린지 상호작용

| 챌린지 | 효과 |
|---|---|
| 황금고블린 추방 | 상점 진입 자체 불가 |
| 새로고침 없음 (`trackNoRefreshEver`) | 사용 시 챌린지 실패 |
| `forbidMagicWeapon` 등 | 차단된 아이템은 상점에서도 잠금 표시 |

---

## 행동 흐름 (`Shop.vue`)

```
[상점 진입] → 슬롯 표시
   ├ 구매 (장비 자동 비교 → ItemDetail 모달)
   ├ 판매 (인벤토리 → 판매가 회수)
   ├ 새로고침 (충전 -1)
   └ 떠나기 → 다음 층 이동
```

인벤토리 가득 차면 `PickupModal` 로 슬롯 교체 / 신규 포기 선택.
