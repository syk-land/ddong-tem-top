시뮬레이션 기반 밸런스 셋업. 모든 수치는 `/src/data/*.ts`, `/src/core/stats.ts`, `/src/core/chapters.ts` 에서 가져옴.

## 캐릭터 베이스라인

### 시작 능력치 (보너스 0, 균등 캐릭)
```
힘 10 / 민첩 10 / 체력 10 / 마력 10 / 행운 10 = 총 50pt
```
주사위 굴림 시: 각 최소 3, 최대 20. 무작위 35pt 분배 (시작 15pt + 35pt = 50pt).

### 5스탯 파생 효과 (`computeEffectiveStats`)
| 스탯 | 파생 |
| --- | --- |
| 힘 | 공격력 × **4.0**, 관통 × 0.5 |
| 민첩 | 속도 × 1.0, 명중 × 0.5, 회피 × 0.5 |
| 체력 | 방어력 × **4.0**, HP = 체력 × 10 + 50, 저항 × 0.5 |
| 마력 | MP = 마력 × 15 + 30, 마력계수 = clamp(1 + (마력 - 15) × 0.05, 0.1, 1.8), 저항 × 0.5 |
| 행운 | 명중/회피/관통/저항 각 × 0.3 |

**시너지**: 로브 + 마법 무기 장착 시 `armorSpeedMult × 1.15` 추가 부스트

균등 캐릭(각 10):
- 공격력 40 (힘만), 방어력 40 (체력만)
- HP 150, MP 180
- 마력계수 0.75 (마법공격력 = 40 × 0.75 = 30)
- 속도 10 × 갑옷 speedMult × 무기 speedCoef
- 명중/회피 8, 관통 8, 저항 13

### 도전 보스 영구 보너스 분배
`pendingStartBonus + permanentStartBonus` 분배: 5스탯에 1/5 균등 + 잔여(0~4)는 힘 → 민첩 → 체력 → 마력 → 행운 순서.

### 트레잇 atk%/def% 단계 (v6)
| 티어 | atk%/def% | 의미 |
| --- | --- | --- |
| 하급 | -0.5 | 페널티 (똥템) |

| 등급 | 목표 best | 현재 best | 비고 |
| --- | --- | --- | --- |
| 노말 | 40% | 13% | 보스 강해서 약함 (의도된 난이도) |

- ch9 기계/천공

## 진짜 보스 도전 카운터 (v6.1)
- `meta.totalGoldEarned` — 클리어 시점 남은 골드 누적 (UI 표시 X)
- **5만 골드 도달 시** 메인메뉴/새캐릭터에서 도전 트리거
- 도전 발동 시 totalGoldEarned 0 리셋

### 누적 보너스 (`totalBonusStats`)
- 매 클리어마다 등급 보너스(1~10pt) 누적 (영구)
- 캐릭터 생성에서 분배 시 *차감 X* (영구 풀)
- **진짜 보스전 후 → 결과 화면 "캐릭터 생성하기" 누름 → 튜토리얼 인트로 시작 시점에 0 리셋**

### 도전 보너스 (`permanentStartBonus`, 영구 누적)
```
gain = floor(60 × 깎은비율)
meta.permanentStartBonus += gain
```
- 1회 도전 max: +60pt (100% 클리어)
- 영구 누적 — 매 캐릭터 시작 스탯에 자동 적용 (5스탯 1/5 균등 분배)
- 100% 클리어 시 `realBossDefeated = true` (게임 클리어 화면)

## 도박사 룰렛 EV (`spinRoulette`)
```
pGreat (+5)    = 0.10 + 행운 × 0.012
pGood  (+2)    = 0.25 (고정)
pNone  (0)     = 0.30 (고정)
pBad   (-2)    = max(0, 0.20 - 행운 × 0.006)
pTerrible(-5)  = max(0, 0.15 - 행운 × 0.006)
```

| 행운 | EV |
| --- | --- |
| 0 | -0.15 (약간 손해) |
| 5 | +0.36 |
| 10 (균등 시작) | +0.87 |
| 20 | +2.0 |

행운 10 이상이면 기대값 양수 — 평균 이득.

```
base = 100 + 50 × 챕터
- 행운: × 1.5 (가장 비쌈)
- 민첩: × 1.2
- 힘/체력/마력: × 1.0 (표준)
```

## 마법계수 산식
```
magicCoef = clamp(1 + (총마력 - 15) × 0.05, 0.1, 1.8)
```
- 마력 15 = 1.0 (기준)
- 마력 1pt당 ±0.05
- 상한 1.8, 하한 0.1
- 마법공격력 = (atkBase + 무기 weaponAtkCoef) × magicCoef

## 향후 조정 메모
- coef 1/2/4/6 격차로 인한 스페셜/레전드 강세 — 사용자 의도 "한두 조합만 best 도달"로 OK
- 챕터 10 trait 강한 보스(기계/천공/언데드/환영) 추가 약화 검토
- 시뮬 노이즈 ±10%p — 100런 이상으로 늘리면 더 정확
- 마법 무기 + 로브 압도 방지 위해 mpBonus 8까지 약화 + 마력계수 cap 1.8 유지
